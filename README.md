# Hello, AI! - Your First AI API Call

> Say "Who are you?" to AI through code—take your first step into AI application development.

## Overview

In previous lessons, you learned how to configure AWS credentials and use `boto3.Session()`. Today, we'll use that knowledge to do something really cool: **call an AI model through code**.

This isn't chatting with ChatGPT in a browser—it's talking directly to enterprise-grade AI models through Python code. Once you master this skill, you'll have the foundation to build any AI application.

## Learning Objectives

After completing this lesson, you will be able to:

1. **Understand the essence of AI APIs** — An AI model is just a function: input a question, get an answer

3. **Call alternative AI services** — Master at least one AI API besides Bedrock (Gemini or GLM)

## Core Concept: AI is Just a Function

Before we start coding, understand this important concept:

```
Your question → [AI Model] → AI's answer
```

No matter how complex AI is, from an application developer's perspective, it's essentially a function:
- **Input**: The question or instruction you give the AI
- **Output**: The response generated by the AI

Just like you don't need to understand engine mechanics to drive a car, you don't need to understand neural networks to call AI.

## Task 1: Run the AWS Bedrock Script (Required)

### Understanding the Code

Open [`scripts/test_ai_aws_bedrock.py`](./scripts/test_ai_aws_bedrock.py):

```python
import boto3
import json

# Create Bedrock client
session = boto3.Session()
bedrock = session.client(
    service_name='bedrock-runtime',
    region_name='us-east-1'
)

# Prepare message
model_id = "us.amazon.nova-micro-v1:0"  # Use the cheapest model
system_prompt = "You are a helpful AI assistant."
user_message = "Who are you? Please answer in a short sentence."

# Build request
messages = [
    {
        "role": "user",
        "content": [{"text": user_message}]
    }
]

# Call API
response = bedrock.converse(
    modelId=model_id,
    messages=messages,
    system=[{"text": system_prompt}],
    inferenceConfig={
        "maxTokens": 200,
        "temperature": 0.7
    }
)

# Extract AI response
ai_response = response['output']['message']['content'][0]['text']
print("AI response:", ai_response)
```

### Code Breakdown

| Code | Purpose |
|------|---------|
| `boto3.Session()` | Create AWS session, auto-reads `~/.aws/credentials` |
| `session.client('bedrock-runtime')` | Create Bedrock service client |
| `model_id` | Specify which AI model to use (Nova Micro is cheapest) |
| `messages` | Conversation history with role (user/assistant) and content |
| `bedrock.converse()` | Core! Send message to AI, get response |

### Run the Script

```bash
python scripts/test_ai_aws_bedrock.py
```

If everything works, you'll see output like:

```
AI response: I'm an AI assistant created by Amazon to be helpful, harmless, and honest.
```

**Congratulations! You've completed your first real AI API call!**

### Common Issues

**Q: Getting `AccessDeniedException`?**

Check the following:
1. Is `~/.aws/credentials` file configured correctly?
2. Does the IAM User have `AmazonBedrockFullAccess` permission?
3. Is model access enabled in the Bedrock console?

**Q: Getting `Could not find credentials`?**

Run this command to verify AWS configuration:
```bash
aws sts get-caller-identity
```
